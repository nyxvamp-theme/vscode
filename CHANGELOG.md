# Change Log

All notable changes to the "nyxvamp-theme" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.1.1]

- Add jhujuba variant, a pink-tinted mid-dark theme
- Lighten comment gray in veil and obsidian for better contrast
- Move constant, boolean, and symbol scopes from pink to gold in veil and obsidian
- Darken radiance string, keyword, type, hint, and diff colors for better contrast

## [0.1.0]

- Massive fixes on color definitions for all variants, specially refecing UI elements
